## 3. Стиль / дизайн

- **Тема:** тёмный luxury по умолчанию + переключатель на светлую (кнопка солнце/луна рядом с логотипом). Выбор запоминается (localStorage).
- **Палитра:** фон `#0B0B0B`, карточки `#111`/`#151515`, текст `#F3F1EC`, вторичный `#8A8A8A`, границы `#292929`, акцент — тёплый золотой amber `#C8863C` (дозированно).
- **Шрифты (Google Fonts):** Cormorant Garamond (заголовки, editorial) + Jost (интерфейс).
- **Валюта:** € (евро).

## 4. Что уже реализовано (всё работает)

- **Заставка (3D-интро):** сборка букв «ADMV» — буквы слетаются из глубины и складываются в слово, последняя буква золотая, затем линия + подпись «Премиальная одежда». Играет при каждом входе/обновлении, внутри сайта не показывается. Есть кнопка «Пропустить».
- **Шапка:** фиксированная, стеклянная (blur), логотип + переключатель темы, навигация, иконки поиска/избранного/корзины, бургер-меню на телефоне.
- **Герой:** фото-заставка кампании ADMV (некликабельная).
- **Магазин (SHOP):** фильтр (категория/размер/цвет/цена), сортировка, переключатель сетки **1 / 2 / 3 / 4** колонки, карточки с hover (второе фото + быстрое добавление + сердечко в избранное).
- **Страница товара:** галерея с миниатюрами, выбор цвета и размера, «В корзину» / «Купить сейчас», блок гарантий.
- **Корзина** (боковая панель): количество, сумма, демо-оформление.
- **Избранное** (боковая панель).
- **Поиск** (полноэкранный overlay): популярное + живые результаты.
- **Виртуальная примерочная** — плавающая панель (кнопка-лаунчер снизу слева). На карточках товара «вешалка» → послойная мужская модель надевает вещь (обувь → низ → верх по z-index). Блок «Your picks» с размерами и ×, общий итог, «Add look to cart» (реально кладёт в ту же корзину), «Start over».
- **Адаптив:** полностью под телефон/планшет/ноутбук/десктоп, без горизонтального скролла.
- **Анимации:** reveal при скролле, магнитные кнопки, тосты. Всё уважает `prefers-reduced-motion`.

## 6. Как обновить сайт

Правки делает Claude. Общий порядок (для справки):

1. Отредактировать `index.html`.
2. Опубликовать:
   ```
   cd ~/Desktop/ADMV-STORE
   git add -A
   git commit -m "описание правки"
   git push origin main
   ```
3. Через ~1 минуту изменения появятся по ссылке (GitHub Pages пересобирает сайт автоматически).
