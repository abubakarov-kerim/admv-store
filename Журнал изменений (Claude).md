# Журнал изменений — ADMV STORE

История правок сайта. Новые записи сверху.

---

## 12.10.2026

- **Валюта: рубли вместо евро.** Цены показываются как «8 900 ₽». Цены стандартных товаров переведены в рубли (умножены на 100: было €89, стало 8 900 ₽). Свои цены, введённые в админке, не меняются. В браузере админа валюта переключается на ₽ автоматически, один раз.
- **Фото загружалось наполовину: найдена причина.** Загруженное фото записывалось в текстовое поле формы, а поле обрезает длинный текст (около 520 тыс. знаков), поэтому у большого фото сохранялась только верхняя часть. Теперь фото хранится отдельно, в поле видна пометка «Загруженное фото (файл)».
- **Сломанные демо-фото.** Сервис loremflickr, откуда брались демо-фото стандартных товаров, перестал отдавать картинки (ошибка 401). Вместо значка «?» теперь показывается заглушка «ADMV · Фото скоро», пока не загружены реальные фото.
- **Загрузка фото через админку исправлена.** Фото теперь автоматически уменьшается и сжимается перед сохранением (товары до 1200 px, заставка до 2000 px), поэтому большие снимки с телефона сохраняются целиком. Загруженные фото показываются в карточке полностью, без обрезки краёв.

## 11.10.2026

- **Заставка под тёмную тему.** В тёмном режиме теперь показывается тёмная версия фото кампании (`images/hero-admv-dark.jpg`): светлый студийный фон заменён на тёмный, люди и одежда остались как были, надписи стали светлыми. В светлом режиме заставка прежняя (`images/hero-admv.jpg`). Переключается вместе с кнопкой темы.
- Если в админке загружено своё фото заставки, оно показывается в обеих темах (отдельной тёмной версии для него нет).
- **Новая цветовая палитра (менялись только цвета).** Чёрный `#101114`, слоновая кость `#F2EFE8`, тауп `#A99B85` вместо прежних чёрного, кремового и янтарного. Тауп заменил янтарный акцент везде: ссылки, выделения, кнопки при наведении, заставка. В светлой теме для акцента взят более тёмный тауп `#75695A`, чтобы текст читался на светлом фоне. Не тронуты: цвета-образцы товаров, фирменные цвета WhatsApp/Telegram/Instagram, красный цвет ошибок, тени, фото.
- **Всё скруглили.** Острые углы убраны по всему сайту: кнопки, «Фильтр», сортировка, сетка, плашки каталога, метки на карточках, иконки на фото, размеры, поля, фото товаров, корзина, админка. Единая система: 10px для кнопок и плашек, 16px для фото и карточек (переменные `--r-xs`, `--r`, `--r-lg` в конце стилей).
- **Заказ через Telegram и Instagram.** Текст заказа теперь подставляется в чат автоматически, как в WhatsApp. На случай, если приложение его не подставит, текст по-прежнему копируется, и его можно вставить вручную.

## 10.10.2026 — редактирование прямо на сайте (инлайн-админка)

- После входа в админку включается **режим редактирования на самом сайте** (как в Shopify/WordPress):
  - сверху тонкая **панель админа** (кнопки: + Товар, Каталог, Магазин, Панель, Выйти);
  - у каждой карточки товара при наведении — **карандаш «изменить»** и **«удалить»** (с подтверждением);
  - на заставке — кнопка **«Изменить заставку»**, в подвале — **«Изменить информацию»**.
- **Фото заставки теперь можно менять из админки** (Магазин → «Фото заставки»: ссылка или загрузка), без переделки файла.
- Режим включается автоматически, пока ты в сессии; «Выйти» — убирает все кнопки. Обычные посетители ничего этого не видят.

## 10.10.2026 — крупное обновление (магазин + админка)

- **Убрана регистрация/аккаунт** и сбор данных пользователей (кнопка «Аккаунт» удалена).
- **База данных товаров** теперь в localStorage со стандартными данными: правишь товары — сайт обновляется сразу. Карточки корректно работают с фото, описанием и характеристиками.
- **Админ-панель** (вход по логину/паролю, по умолчанию `admin` / `admv2026` — смени в разделе «Доступ»). Открывается по ссылке «Админ-панель» в подвале или по адресу `…/#admin`. Разделы:
  - **Товары** — добавить/изменить/удалить (фото ссылкой или загрузкой, описание, характеристики, цена, старая цена, цвета, размеры, метки).
  - **Каталог** — категории (брюки, футболки, обувь…), добавить/переименовать/удалить.
  - **Магазин** — название, текст, адрес, время работы, контакты (Telegram/WhatsApp/Instagram), валюта.
  - **Доступ** — смена логина/пароля.
  - **База** — экспорт/импорт JSON (резервная копия, перенос, публикация для всех) + сброс к стандартным.
  - **На каждое изменение/удаление — окно подтверждения** (чтобы не нажать случайно).
- **Окно заказа в корзине**: «Оформить заказ» → готовый текст заказа + выбор менеджера **WhatsApp / Telegram / Instagram** (текст копируется и открывается чат).
- **Каталог-полоса** категорий в магазине (и ссылки в подвале) с фильтрацией.
- **Подвал с информацией о магазине**: название, адрес, время работы, контакты — всё из админки.
- **Плавающая кнопка Telegram** в правом нижнем углу → чат продавца.
- **Полная мобильная адаптация** всех новых блоков (админка, окно заказа, каталог, формы, кнопки).
- Исправлен баг: функция `open()` перекрывала системную `window.open` (ссылки заказа не открывались).
- Важно (ограничение статического сайта): изменения в админке сохраняются **в браузере администратора**. Чтобы их увидели ВСЕ — «База» → «Экспорт» и прислать файл для публикации.
